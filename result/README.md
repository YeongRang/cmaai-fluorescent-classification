# Results

This directory contains the main outputs generated from the descriptor analysis, fluorescence classification, and model interpretation.

## Folders

- `02_Analysis/`  
  Contains descriptor distribution plots and comparative visualization results.  
  Generated from `code/02_Descriptor_Analysis.ipynb`.

- `03_Classification/`  
  Contains the repeated classification evaluation results and summary statistics.  
  Generated from `code/03_Fluorescent_Classification_Model.ipynb`.

- `04_Interpretation/`  
  Contains Integrated Gradients-based interpretation results, including attribution data, molecular-level results, ECFP bit-level analysis, and related figures.  
  Generated from `code/04_Fluorescent_Model_Interpretation.ipynb`.

- `05_DrawGraph/`  
  Contains final visualization figures generated from the global Integrated Gradients analysis.  
  Generated from `code/05_Draw_Graph_GlobalIG.ipynb`.
