# Data

This directory contains the molecular structure datasets used for fluorescence classification.

## Files

### `fluorescent.csv`

Dataset of fluorescent organic molecules.

- Contains molecular structures represented as SMILES.
- Fluorescent molecules were collected from the ChemFluor dataset.
- The SMILES were canonicalized and duplicate structures were removed during preprocessing.

### `nonfluorescent.csv`

Dataset of non-fluorescent organic colorants.

- Contains molecular structures represented as SMILES.
- Non-fluorescent molecules were collected from the World Dye Variety database.
- The SMILES were canonicalized and duplicate structures were removed during preprocessing.

### `fluorclass_dataset.csv`

Final dataset used for development and evaluation of the fluorescence classification model.

- Generated by combining the fluorescent and non-fluorescent datasets.
- Molecular structures were canonicalized using RDKit.
- Invalid SMILES were removed.
- Duplicate molecules were removed based on canonical SMILES.
- Contains 5,466 unique molecules:
  - 2,912 fluorescent molecules
  - 2,554 non-fluorescent molecules

This dataset was used to generate 2,048-bit Extended-Connectivity Fingerprints (ECFP) with a radius of 4 for machine learning analysis.

## Preprocessing

The preprocessing procedure is provided in:

`code/01_Data_Preprocessing.ipynb`

The main preprocessing steps were:

1. Load the fluorescent and non-fluorescent molecular datasets.
2. Convert SMILES into canonical SMILES using RDKit.
3. Remove invalid molecular structures.
4. Remove duplicate structures.
5. Assign fluorescence class information.
6. Combine the two datasets into the final classification dataset.
