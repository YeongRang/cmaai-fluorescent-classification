# Code

This directory contains the notebooks used for data preprocessing, descriptor analysis, model development, and model interpretation.

## Notebooks

- `01_Data_Preprocessing.ipynb`  
  Preprocesses the fluorescent and non-fluorescent datasets and generates the final classification dataset.

- `02_Descriptor_Analysis.ipynb`  
  Analyzes molecular descriptors and fingerprint characteristics of the dataset.

- `03_Fluorescent_Classification_Model.ipynb`  
  Develops and evaluates the fluorescence classification model using ECFP and a multilayer perceptron.

- `04_Fluorescent_Model_Interpretation.ipynb`  
  Performs Integrated Gradients-based model interpretation and generates molecular- and ECFP bit-level attribution results.

- `05_Draw_Graph_GlobalIG.ipynb`  
  Visualizes and analyzes the global Integrated Gradients results, including attribution distributions and ECFP bit-level contributions.
